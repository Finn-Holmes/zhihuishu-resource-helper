# 智慧树学习资源逐个打开与视频播放（v1.2.6）

适配域名：`ai-smart-course-student-pro.zhihuishu.com` 的“新形态课程”。

## 第一次使用：安装到 Edge

下面以 Microsoft Edge 为例。需要准备两样东西：浏览器扩展 **Tampermonkey（篡改猴）**，以及仓库中的 **[`zhihuishu-open-resources.user.js`](./zhihuishu-open-resources.user.js)**。
### 第一步：安装篡改猴

1. 打开 **Microsoft Edge 浏览器**。
2. 访问 [Edge 商店中的 Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)，按商店提示安装扩展。
3. 安装完成后，点击浏览器右上角的 **“扩展”按钮（通常是拼图图标）**，找到 Tampermonkey。可以把它固定或显示在工具栏，方便以后打开。
4. 如果工具栏没有看到它，在 Edge 地址栏输入 `edge://extensions` 并回车，在扩展列表里查找 **Tampermonkey**，确认扩展已开启。

Chrome 用户可使用 [Chrome 商店中的 Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)，后续导入脚本步骤相同，扩展管理地址为 `chrome://extensions`。

**课程必须在安装了篡改猴的那个浏览器中打开。** 在 Edge 安装扩展，不会让聊天右侧的内置浏览器自动获得该扩展或脚本。

### 第二步：确认用户脚本运行权限

1. 在 Edge 地址栏输入 `edge://extensions` 并回车。
2. 找到 **Tampermonkey → 详细信息**。
3. 如果有 **“允许用户脚本”** 开关，将其打开。不同 Edge／篡改猴版本的选项可能不同；若没有这一项，查看篡改猴弹出菜单是否提示需要在扩展管理页面开启 **“开发人员模式”**，按提示设置。
4. 检查扩展对当前智慧树网站的访问权限。若权限设置为“单击时”，需为当前课程网站允许访问，否则刷新后可能无法自动运行。

这一节对应此前遇到的“安装了脚本，但是右下角没有面板”。扩展已安装、脚本已保存、用户脚本允许运行是不同的检查项。

### 第三步：找到并复制脚本文件

在 GitHub 仓库首页点击 **Code → Download ZIP**，下载后解压。也可以打开上面的脚本文件，使用 GitHub 的 **Raw / Download raw file** 获取完整源码。

1. 打开下载后解压的项目文件夹。
2. 找到 `zhihuishu-open-resources.user.js`。如果文件扩展名被隐藏，显示名称可能少了最后的 `.js`；可以在资源管理器中开启“文件扩展名”查看完整名称。
3. 右键文件 → **打开方式 → 记事本**。
4. 在记事本中按 **Ctrl + A** 全选，再按 **Ctrl + C** 复制全部代码。

要复制的是这个 `.user.js` 文件的完整代码，包含开头的 `// ==UserScript==` 和结尾的 `})();`。README 是使用说明，不是脚本；不要复制提交差异视图中的红绿对比内容，也不要把新代码追加到旧代码后面。

### 第四步：把代码保存到篡改猴

1. 点击 Edge 右上角 **Tampermonkey 图标**，选择 **“添加新脚本”**（不同版本也可能叫“新建脚本”）。
2. 点击脚本编辑区，按 **Ctrl + A** 选中默认示例代码。
3. 按 **Ctrl + V**，用刚才复制的完整代码替换默认内容。
4. 按 **Ctrl + S** 保存。
5. 返回 Tampermonkey 的 **“管理面板”**，应能看到“**智慧树新形态课程 · 学习资源逐个打开**”，确认这一行的启用开关已打开。当前脚本版本应为 **1.2.6**。

如果以前已经安装过本脚本，请使用后面的“更新已有脚本”步骤，编辑原有脚本即可。

### 第五步：在 Edge 打开课程

1. 在 **Edge** 中打开智慧树并登录，进入对应课程。
2. 在课程目录里打开任意一个知识点，进入能看到教材、PPT、视频等资源卡片的页面。
3. 检查地址栏：本脚本适配的学习页面地址形如：

   ```text
   https://ai-smart-course-student-pro.zhihuishu.com/learnPage/课程ID/知识点ID/班级ID
   ```

   末尾带 `?catalogActiveTab=personal` 等参数也可以。

4. 保存脚本后若课程已经开着，按 **Ctrl + R** 刷新一次。
5. 页面右下角应出现 **“学习资源逐个打开 · v1.2.6”** 面板。只看到标题时，点击标题展开。

其他域名下的智慧树首页、AI 教学中心等页面不在本脚本的匹配范围内。同一域名下可能也会显示面板，但执行任务需要先进入网址含 `/learnPage/` 的知识点页面。

### 第六步：先试跑，再处理全部知识点

1. 将面板中的 **“范围”** 选为 **“仅当前知识点（试跑）”**。
2. 点击 **“扫描”**，查看是否识别到了知识点目录和当前资源。
3. 根据下面的选项说明调整设置，点击 **“开始 / 继续”**。
4. 观察资源卡片是否切换、面板是否显示当前资源和日志。如果当前知识点有未完成的视频，脚本需要等视频正常播完；不是几秒后就切换。
5. 当前知识点处理结束后，把“范围”改为 **“全部知识点”**，再次点击 **“开始 / 继续”**。

**选择“全部知识点”后，不需要你逐个点击知识单元。** 脚本会按目录顺序展开模块、单元，进入知识点并处理资源。选择“仅当前知识点”时，当前知识点完成后停止是正常行为。

运行期间想改设置或自己切换知识点，先点击“暂停”；再改设置或切换页面，最后点击“开始 / 继续”。

## 面板里的选项和按钮

| 选项／按钮 | 用途和建议 |
| --- | --- |
| 范围：全部知识点 | 遍历整门课当前目录中的知识点，自动展开和切换。 |
| 范围：仅当前知识点（试跑） | 只处理你当前选中的知识点，适合首次验证。 |
| 图文每次随机停留 1～5 秒 | 默认开启；每个图文资源单独随机选取 1、2、3、4 或 5 秒，所选时长会写入日志。 |
| 图文固定停留 | 取消随机停留后出现，可填写 1～60 秒，默认值是 4 秒。 |
| 跳过本标签页已访问记录 | 默认开启；已经由脚本访问成功的图文资源会跳过。旧版标记为“跳过”的视频仍会处理。 |
| 播放未完成的视频（含选学） | 默认开启；取消后只处理非视频资源。 |
| 静音播放 | 默认开启；想听声音可在暂停任务后取消，再继续。 |
| 扫描 | 读取目录、当前资源数量和已有记录，不开始遍历。 |
| 开始 / 继续 | 开始处理资源；暂停后，在相同设置和对应知识点下接续原任务。 |
| 暂停 | 停止后续操作，并暂停当前视频。快捷键为 **Alt + Shift + S**。 |
| 导出记录 | 下载包含访问结果、运行位置、设置和日志的 JSON 文件，便于保存或排查。 |
| 清空访问记录 | 清空本课程在当前标签页中的脚本访问记录和保存的运行队列，不改变网站的学习进度。一般排查不需要先清空。 |

设置在任务运行期间不可修改，先暂停即可调整。网站已经标记完成的视频会直接跳过，不因取消“跳过已访问记录”而强制重播。

## 更新已有脚本

本地文件更新后，篡改猴中已经保存的副本不会自动跟着更新。每次拿到新版代码，需要执行：

1. 在课程面板中点击 **“暂停”**。
2. 用记事本打开本文件夹中的最新版 `zhihuishu-open-resources.user.js`，按 **Ctrl + A → Ctrl + C** 复制全文。
3. 在 Edge 中点击 **Tampermonkey → 管理面板**，找到原来的智慧树脚本，点击脚本名称或编辑按钮。
4. 在编辑区按 **Ctrl + A → Ctrl + V**，替换整份代码，再按 **Ctrl + S** 保存。
5. 回到课程页面，按 **Ctrl + R** 刷新。
6. 确认面板标题显示 **v1.2.6**，再点击“开始 / 继续”。如果仍显示旧版本，检查是否保存成功、是否刷新了正确的课程标签页，以及是否存在多份同名脚本。

已有访问记录会保留。由 v1.0／v1.1 升级到视频版时，需要点击开始重新扫描，以补上此前跳过的视频；v1.2 的运行位置可以恢复，新增的图文随机停留默认开启。

## 查看日志和反馈问题

日志在**右下角脚本面板内的最底部**，位于“导出记录”“清空访问记录”等按钮下方，有“**运行日志**”标题和一个文字框。

1. 如果面板收起了，先点击“学习资源逐个打开”的标题展开。
2. 如果面板内容比屏幕高，将鼠标放在**面板内部**向下滚动，找到“运行日志”。
3. 将鼠标放进日志文字框，再向下滚动，可以查看最新记录。
4. 可以选择最后几行文字复制，也可以截取包含面板版本、状态文字和日志的截图。
5. 不方便选择文字时，点击 **“导出记录”**，下载的 JSON 文件中也包含日志。

日志文字示例（仅演示格式）：

```text
13:20:10 正在打开资源：第1章-计算机网络概述.ppt
13:20:11 图文停留 3 秒（随机）：第1章-计算机网络概述.ppt
13:20:14 网站已完成：第1章-计算机网络概述.ppt
```

日志保留最近 80 条，正常刷新后会恢复。还没开始运行时，也应看到“暂无运行日志……”的提示。要反馈问题，提供 **面板版本、范围设置、出问题的资源名称、面板状态和最后约 10 行日志**，或直接提供面板截图／导出的记录文件。

## 常见问题

### 1. 右下角没有出现面板

按顺序检查：

1. 课程是否在安装了篡改猴的 **Edge** 中打开，而不是另一个浏览器。
2. 地址栏的域名是否为 `ai-smart-course-student-pro.zhihuishu.com`。
3. 在课程页面点击篡改猴图标，菜单里是否出现了本脚本。没有出现时，优先核对网址、脚本是否保存启用，以及代码开头的 `@match` 等信息是否完整。
4. 脚本已经列出但面板没有出现时，按前面的“用户脚本运行权限”步骤检查，再刷新课程页面。
5. 在管理面板中确认只启用一份本脚本，且保存的是完整代码。

仍不显示时，按 **F12 → 控制台（Console）**，保持控制台打开并刷新页面，查看红色报错。如果看到 `userscript.html` 的 `SyntaxError` 或 `Unexpected token`，可能复制了不完整代码或混入新旧两版代码。重新下载完整脚本，在篡改猴代码区 **Ctrl + A → Ctrl + V** 全量替换，**Ctrl + S** 保存后刷新。反馈时提供报错行及上下文截图。

### 2. 点击开始后页面刷新，面板看起来又重置了

v1.0 的运行位置和日志只在内存中，整页刷新后会丢失。这是此前已经修复的问题，使用当前 **v1.2.6**。

新版正常表现是：页面跳转或刷新 → 面板重新出现 → 显示恢复提示 → 等目录和资源加载完成 → 自动继续。网站初始化时需要等待，短暂重新显示面板并不代表访问记录被清空。

如果刷新后一直停在初始提示且日志也没有恢复，先确认面板版本和当前域名，继续在**同一个标签页**使用。此前已暂停或已报错的任务在刷新后会保持停止，需要手动点击继续；尚未开始过的任务也不会自动启动。

### 3. 是不是需要手动逐个点击知识单元

不用。选择“**全部知识点**”即可自动展开并切换。只处理当前知识点通常是选了“仅当前知识点（试跑）”。如果已经选择全部仍停住，查看面板状态和最后几条日志，而不是继续手动点其他知识点。

### 4. 视频播完了，但没有立刻切换

v1.2.2 起修复了正常播放结束后的暂停被误报为异常的问题：记录视频结束事件，暂停时最多等待 3 秒让结束状态更新。若停在距末尾不超过 1 秒的位置，则进入网站完成状态核对，不直接把视频记为完成。中途持续暂停或弹题仍会停止。

脚本正在等网站确认完成。现场观察到的“计算机网络的拓扑结构”视频，在播放结束后卡片仍显示旧的 3%，刷新才更新为“已完成”。

新版会先等待最多 15 秒；卡片仍未更新时自动刷新一次核对，并接续当前任务。**v1.2.3 新增自动补播**：观察到正常播放结束，但刷新后网站仍未显示完成时，从头按原速再播放，最多补播 2 次。补播期间网站显示“已完成”或“100%”就继续下一项；若仍未更新，则等本次播完后再次刷新核对。重试次数保存在当前任务中，刷新或暂停后继续不会重置。

日志会显示“自动补播 1/2”或“自动补播 2/2”。达到上限后仍未完成才停止；仅在末尾暂停、没有观察到正常结束事件且刷新后未完成时，也会停止以便检查题目或播放器。已因旧版的完成核对错误停止的任务，升级后点击“开始 / 继续”即可进入此流程。

### 5. 视频没有自动播放，或者中途停了

- 出现 `NotAllowedError` 或“浏览器未允许播放”时，手动点击播放器的播放按钮，再点击脚本“开始 / 继续”。
- 出现题目时，先完成题目，再点击脚本继续；当前版本不自动答题。
- 没有题目但提示 60 秒无进展时，检查视频是否在缓冲、网络是否正常。能手动正常播放后再继续。
- 主动点击脚本“暂停”也会暂停视频，这是预期行为。

目前并未实际观察到这门课的弹题；部分视频没有弹题时，按普通播放流程使用即可，不需要配置额外 API。

### 6. 已经选了随机 1～5 秒，为什么有时停得更久

1～5 秒是每项图文的等待时长，不包含目录展开、知识点切换、页面加载和预览验证耗时。网络慢或页面刷新时，总停留时间会更长。视频播放不受这个随机时间控制，需要正常播完。

随机时间也不能保证平台无法识别脚本，网站显示完成与平台是否认可自动化行为是两个不同的问题。

### 7. 为什么还有资源被跳过

看日志里的具体原因：图文可能已有脚本访问记录；视频可能已被网站标记完成，或关闭了视频播放选项；音频目前不支持，会跳过并记录。新版开启视频后会处理旧版跳过的未完成视频，不必为此清空图文记录。

### 8. 刷新、关闭标签页和重新打开有什么区别

同一标签页正常刷新通常保留访问记录、设置、日志和运行位置；关闭标签页后不保证保留。需要留存结果时先“导出记录”。导出文件用于查看和排查，当前版本没有从该文件导入进度的按钮。

保持电脑唤醒、课程标签页打开；后台标签页可能被浏览器限速。同一课程建议只在一个标签页运行，遇到“另一个标签页正在处理”时，先暂停那一页。

### 9. 百度、知乎等外部文章会打开新标签页

v1.2.6 支持直接打开 `about:blank`、空网址或未传网址的资源：关闭本次空白页后核对课程卡片，只要网站显示“已完成”，就继续下一项，不再因缺少正文预览报错。空白页本身不代表学习完成；卡片未完成时仍会刷新核对一次，之后仍未完成才停止。旧版因空白页报错的任务，升级后点击“开始 / 继续”，对应卡片已完成时会直接接续，不用清空访问记录。旧版遗留的空白标签页请手动关闭。

v1.2.4 新增外部资源处理：脚本点击资源后，捕获该次操作打开的外部 HTTP(S) 页面或空白页，关闭新标签页，再检查原课程页中对应资源的“已完成”标记。这类资源不要求课程页出现内嵌正文，也不要求卡片保持选中。若标记 15 秒内未更新，则刷新核对一次；仍未完成会停止。

支持常见的 `window.open(文章网址)` 和资源卡片中的外部超链接。只关闭本次捕获的新窗口，原有标签页不受影响；运行中手动点击或按键会停止捕获新窗口。为避免误关联，捕获窗口限于资源点击后的 10 秒。自动刷新后只核对已有记录，不重复打开文章页。

v1.2.5 起改用篡改猴的 `GM_openInTab` 打开独立后台标签页，通过扩展句柄关闭，不依赖原生 `window.open` 返回窗口引用，因此可处理 `noopener` 链接和原生弹窗被拦截的场景。新增 `GM_openInTab` 和 `unsafeWindow` 权限：更新时务必包含文件开头的权限声明；如果篡改猴提示新增权限，确认后保存并刷新课程页面。

从 v1.2.4 的“未取得外部资源标签页的控制权”错误升级时，先手动关闭旧版遗留的文章标签页，再点“开始 / 继续”。脚本会重新用扩展打开并处理当前资源，保留其他已访问记录。扩展未提供标签页接口或未允许关闭时仍会明确报错，不把资源直接记为完成。

当前不支持直接替换课程页地址的外链跳转、先打开空白页再另行赋值地址、跨域 iframe 内发起的新窗口，或网站提前缓存了原始 `window.open` 的情况。外部资源打开调用返回 `null`（与 `noopener` 一致），不支持网站拿返回窗口继续执行 `focus()` 或修改地址的用法。外部文章窗口的加载与读取内容不在验证范围内，最终完成状态以课程卡片为准。

## 行为

- 逐一展开知识点目录，通过网页原有资源卡片点击打开资源。
- 默认每项图文资源独立随机选择 **1、2、3、4 或 5 秒**作为停留时间，日志和导出记录会保存所选秒数。整页跳转后沿用该资源已经选择的时长。取消“图文每次随机停留 1～5 秒”可设置固定时长（默认 4 秒，可调为 1～60 秒）。
- 仍会等待资源列表稳定、资源被选中和预览可见；加载慢时实际页面停留可能超过 5 秒。随机设置只作用于图文，视频仍需正常播完并检查网站完成状态。随机等待不能保证不被平台识别为自动化操作。
- 视频按 1 倍速正常播放，页面面板显示当前播放时间和总时长，日志每 30 秒记录一次播放进度。音频仍跳过；取消“播放未完成的视频”可使用原来的非视频资源模式。
- 视频完成以资源卡片显示“已完成”或“100%”为准。正常播完后卡片 15 秒内未更新，会保存当前位置并刷新核对；仍未完成则从头原速补播，最多补播 2 次。每次补播结束后至多刷新核对一次，仍失败则停止。补播期间网站已确认完成时，可提前结束补播并继续下一资源。
- 网站已标记完成的视频直接跳过；历史脚本记录不会覆盖网站当前显示的未完成状态。第一次运行也会打开网站已标记完成的非视频资源。勾选“跳过本标签页已访问记录”时，继续运行会跳过脚本已成功访问的非视频资源；取消勾选可以重新访问它们。
- 访问记录、运行队列、设置和最近 80 条日志按课程和班级隔离，保存在当前标签页的 `sessionStorage`；刷新通常保留，关闭标签页后不保证保留。
- **运行中整页刷新或知识点跳转会自动接续**，从保存的目标知识点继续，不从队首重新跳转。新页面会先等待知识点目录初始化。尚未点击开始、已暂停、已报错或已结束的任务不会在刷新后自动运行。
- 如果资源卡片点击引起整页加载，新页面先验证该资源是否已被选中，再等待预览并记录；不会一加载就重新点击已选中的卡片。无法保持选中的资源最多点击两次，然后停止并记录原因。
- “暂停”或 `Alt + Shift + S` 会中断后续操作并暂停当前视频；已经发出的卡片点击无法撤销。相同设置下继续暂停的任务会使用原来的队列位置，视频仍选中时不重新点击卡片。
- 视频出现可见弹窗或播放器中途暂停时，脚本停止等待。**本版本不自动答题**：处理题目后点“开始 / 继续”。若浏览器阻止自动播放，先手动点击播放器播放，再点脚本继续。实际弹题样式尚未现场观察，未识别为弹窗但导致播放器暂停的题目也会触发停止。
- 视频连续 60 秒无播放进展、播放器加载失败或视频源变化时停止，保留日志。首次播放依靠网站恢复进度；仅开始补播时把播放位置设为 0，从头正常播放，不向前跳过内容，不伪造学习上报。补播中暂停后继续会保留当前播放位置。
- 网站出现弹窗、加载超时或运行中手动切换知识点，脚本停止并显示原因；处理后可继续。
- 支持 Web Locks 的浏览器会阻止同一课程在多个标签页同时运行。
- 点击面板标题可收起面板。建议保持电脑唤醒、课程标签页打开；后台标签页可能被浏览器限速。
- 日志位于面板底部的“运行日志”框，刷新后会恢复，未运行时也有提示文字。暂停状态在点击暂停时立即保存，避免跳转后重新启动。

## 结果如何理解

“已访问”表示脚本已选中资源、等待指定时间并检测到预览区域有内容。

“网站已完成”来自资源卡片上的“已完成”文字。脚本分别记录这两个状态；不会把“已访问”直接当作网站完成，也不调用或修改学习进度接口。预览可见检查不能保证每一页或跨域 iframe 内部内容都加载成功。

“导出记录”得到 JSON，包含每个资源的知识点、名称、必学/选学分组、访问时间，以及是否观察到网站完成标记；也包含运行位置、设置和日志，便于排查。`video-complete` 表示已确认视频完成，`skipped-media` 表示跳过的音频或未启用播放时跳过的视频。

当前课程现场检查识别到 125 个知识点。在“计算机网络定义与分类”中，点击 PPT 后，卡片从没有完成标记变为“已完成”。这只能证明该资源的观察结果，不代表所有资源仅打开就会获得完整学习进度。

本次现场观察“计算机网络的拓扑结构”视频（约 5 分 24 秒）：正常播放至 `ended` 后卡片仍显示旧的 3%，整页刷新后变为“已完成”。这验证了该视频的正常播放与刷新确认流程；不代表整门课程或所有弹题均已验证。

## 适配边界

脚本依据 2026-09-11 实际页面中的 `.section-item-collapse-info`、`.resources-section`、`.basic-info-video-card-container` 等结构编写。目录需已挂载在 DOM 中（折叠隐藏的目录也能读取）；当前课程满足这一条件。未来若网站改为懒加载目录或分页资源列表，需更新适配器。资源卡片数量与“全部”数量不一致时会超时停止，避免漏掉资源却报告本轮结束。

视频适配当前页面内 `.video-player-wrapper` 中的 HTML5 `<video>` 播放器；暂不支持跨域 iframe 内的视频、音频资源或自动答题。任务、作业、考试和 AI 对话不在处理范围内。
